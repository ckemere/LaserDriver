# JLCPCB order files

Per board, generated by that project's `tools/make_fab.py` (KiCad's bundled Python):

| Folder | Board | Contents |
|---|---|---|
| `StimHAT/` | StimHAT (4-layer, 65 × 57 mm) | gerbers zip, JLC BOM / CPL, top / bottom renders |
| `LaserDriverHAT/` | LaserDriverHAT (4-layer, 65 × 57 mm) | same |
| `DCDCPod/` | DCDCPod (2-layer, 31 × 22.5 mm) | same, plus a perspective render and a README (hand-fitted parts) |
| `orders/` | the archives actually uploaded on 2026-11-01 (rev 3 production, Fabrication Toolkit output) | `*_rev3_production.zip` |

The SimpleBatteryPack's order files are the Fabrication Toolkit's, in `../SimpleBatteryPack/production/`.
The loose folders can lag the hand edits made before ordering; `orders/` is what was built.  Unzipped `gerbers/`
folders are ignored by git.

**Before ordering:** check rotations in JLC's placement preview (the generated CPLs carry the Fabrication Toolkit's
per-package offsets from each project's `tools/ref/jlc_rotations.csv`); confirm ICs, diodes, LEDs, transistors,
switches and connectors.  The HATs' Pi header J1 is hand-fitted: Samtec HLE-120-02-xxx-DV-BE bottom-entry socket (the
Harwin M20-7812045 does not fit the footprint).  Hand-fitted and DNP parts are excluded from BOM and CPL (JLC rejects
BOM lines without a placement); each board's README lists them.

The order files of the archived boards (Rev 2 HAT, LaserDaughter, EStimDaughter, relay BatteryPack) and the 2026-10-01
order archives are at tag `archive/pre-glance-cleanup` (`LaserHAT/fab/`).
